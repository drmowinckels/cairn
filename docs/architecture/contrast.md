# Contrast audit

This document records the WCAG contrast ratios for every Cairn text-token /
surface-token pair, across light, dark, and high-contrast (HC) variants. It
is generated by `scripts/contrast-matrix.mjs`:

```sh
node scripts/contrast-matrix.mjs src/brand.css
```

## Thresholds

- **Body text** (everything ≤ 18px and ≤ 14px bold): 4.5:1
- **Large text** (≥ 18px or ≥ 14px bold, weight ≥ 700): 3:1
- **High-contrast mode** (`data-high-contrast="on"`): 7:1 across the board
- **Non-text UI** (dots, dividers, focus rings): 3:1

Cairn body text is 14.5–16px regular, so the audit treats every text token
as body text and requires 4.5:1 / 7:1.

## Token roles

The semantic tokens split into two groups:

| Role                 | Tokens                                                            |
| -------------------- | ----------------------------------------------------------------- |
| Text (`color:`)      | `--ink`, `--ink-soft`, `--ink-mute`, `--accent-ink`, `--teal-ink` |
| Fills, borders, dots | `--accent`, `--teal`, `--indigo`, `--ink-faint`                   |

`--accent-ink` and `--teal-ink` exist because the brand colours
(`--burnt-peach`, `--muted-teal`) are too light to use directly as body
text in the light theme — they pass 4.5:1 only as fills on dark surfaces.
The brand colours remain available via `--accent` / `--teal` for buttons,
chips, project dots, and focus rings, where 3:1 against the surface is
sufficient.

`--ink-faint` is deliberately decorative. It only appears as the colour of
1px dividers, drag-handle icons, and chevrons — never as text. The one
former text consumer (`.bar-h` weekly-chart hour labels) was switched to
`--ink-mute`.

## Method

`scripts/contrast-matrix.mjs` parses `src/brand.css`, resolves each semantic
token (including `var()` indirection) under four scopes — light, dark,
HC-light, HC-dark — flattens any `rgba(...)` foreground against the resolved
opaque surface, then computes the WCAG-2 relative-luminance contrast ratio
via the standard sRGB → linear → luminance pipeline.

`color-contrast` is enabled in `scripts/audit-a11y.mjs`. The puppeteer audit
runs axe-core against the rendered renderer in both colour schemes on every
tab and must stay green.
